# AdGuard VPN GUI для Linux
В силу того, что на данный момент у Adguardvpn нет графического интерфейса на Linux возникла идея реализации простого GUI.
Данный интерфейс по-сути выполняет команды официальной утилиты и для его работы необходимо иметь установленный официальный пакет AdguardVPN
(https://adguard-vpn.com/ru/linux/overview.html#how_to_install)

Приложение обеспечивает простой доступ ко всем основным функциям AdGuard VPN прямо с рабочего стола, избавляя от необходимости постоянно использовать команды терминала.

## Возможности

- **Авторизация** — вход и выход из аккаунта AdGuard
- **Управление локациями** — просмотр доступных VPN серверов с удобным поиском
- **Быстрое подключение** — одним кликом подключиться к VPN или отключиться
- **Статус и информация** — просмотр текущего статуса соединения и информации о лицензии
- **Дополнительные команды** — проверка обновлений, экспорт логов, обновление приложения и редактирование конфигурации

## Требования

- **Python 3.8** или выше
- **PyQt5** — для графического интерфейса
- **adguardvpn-cli** — официальная утилита AdGuard VPN (должна быть установлена и доступна в PATH)

## Установка

### Шаг 1: Клонируйте репозиторий

```bash
git clone https://github.com/yourusername/ui-ux_adguardvpn.git
cd ui-ux_adguardvpn
```

### Шаг 2: Установите зависимости Python

```bash
python3 -m pip install -r requirements.txt
```

### Шаг 3: Установите AdGuard VPN CLI (если не установлен)

Следуйте инструкциям на официальном сайте AdGuard для вашего дистрибутива Linux.

## Использование

### Быстрый запуск

```bash
python3 main.py
```

### Интеграция с рабочим столом (запуск в один клик)

В проекте предусмотрены два вспомогательных скрипта:

- **`run_adguardvpn_gui.sh`** — универсальный запускатель, автоматически использующий виртуальное окружение `.venv` если оно есть, иначе системный `python3`
- **`install_desktop.sh`** — установщик, который создаёт ярлык приложения в меню системы

**Установка ярлыка:**

```bash
chmod +x run_adguardvpn_gui.sh install_desktop.sh
./install_desktop.sh
```

После установки приложение появится в меню в категории "Интернет" (Network) и его можно будет запускать как обычное приложение.

**Удаление ярлыка:**

```bash
rm ~/.local/share/applications/AdGuardVPN-GUI.desktop
```

### Иконка приложения

По умолчанию установщик использует файл `icon.svg` из корня проекта. Если вы хотите заменить иконку:

1. Положите файл `icon.svg` (рекомендуется векторный формат SVG) в корень проекта
2. Или положите `icon.png` (размер 64×64 пикселей) в корень проекта
3. При необходимости отредактируйте путь к иконке в файле `~/.local/share/applications/AdGuardVPN-GUI.desktop`

## Запуск без sudo

Некоторым операциям `adguardvpn-cli` требуются повышенные сетевые привилегии. Чтобы избежать постоянного ввода sudo пароля, есть несколько вариантов:

### Вариант 1: Использование Linux capabilities

Самый простой и безопасный способ. Даёт бинарному файлу точно те привилегии, которые ему нужны:

```bash
# Узнайте полный путь к бинарю
which adguardvpn-cli (путь выданный по данной команде может быть symbolic link)

# Дайте необходимые capabilities (замените путь на реальный)
sudo setcap cap_net_admin,cap_net_raw+eip /usr/bin/adguardvpn-cli

# Проверьте что capabilities установлены
getcap /usr/bin/adguardvpn-cli
# Результат: /usr/bin/adguardvpn-cli = cap_net_admin,cap_net_raw+eip
```

**Удаление capabilities (если требуется обратно):**

```bash
sudo setcap -r /usr/bin/adguardvpn-cli
```

### Вариант 2: Использование systemd сервиса

Более сложный, но универсальный способ для продвинутых пользователей. Запустите `adguardvpn-cli` как systemd сервис с правами root и управляйте им через `systemctl`.

## Примеры использования

### Подключение к VPN в один клик

1. Запустите приложение одним из способов:
   - `python3 main.py` — прямой запуск из папки проекта
   - `./run_adguardvpn_gui.sh` — использование универсального скрипта запуска
   - Установите в систему через `./install_desktop.sh` для быстрого доступа из меню приложений
2. Авторизируйтесь при первом запуске
3. Выберите необходимую локацию из списка
4. Нажмите кнопку "Подключиться"

### Поиск локации

Используйте поле поиска для быстрого поиска по названию страны или города.

### Проверка статуса

В окне приложения отображается текущий статус подключения, ваш IP адрес и информация о лицензии.

## Требуемые разрешения

- **Доступ в PATH**: `adguardvpn-cli` должна быть доступна из терминала (см/ шапку - установка утилиты adguardvpn-cli)
- **Сетевые привилегии**: для подключения/отключения VPN требуются привилегии (см. раздел "Запуск без sudo")
- **Домашняя директория**: приложение создаёт кэш в `~/.cache` (опционально)

## Решение проблем

**Ошибка: "adguardvpn-cli не найдена"**
- Проверьте, установлена ли утилита: `which adguardvpn-cli`
- Добавьте путь в PATH если требуется

**Ошибка при подключении: "Permission denied"**
- Следуйте инструкциям в разделе "Запуск без sudo"
- Убедитесь что capabilities установлены: `getcap $(which adguardvpn-cli)`

**Приложение не запускается**
- Проверьте что установлены все зависимости: `pip3 install -r requirements.txt`
- Проверьте версию Python: `python3 --version` (нужна 3.8+)
